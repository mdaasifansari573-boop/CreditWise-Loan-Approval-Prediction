# CreditWise – Loan Approval Prediction

## Project Overview

CreditWise is a Machine Learning project that predicts loan approval based on applicant financial and demographic information.

## Objective

The main objective of this project is to analyze loan applicant data and build Machine Learning classification models to predict whether a loan application is likely to be approved.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Workflow

1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Data Preprocessing
5. Feature Engineering
6. Model Training
7. Model Evaluation
8. Loan Approval Prediction

## Machine Learning Models

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Naive Bayes

## Evaluation Metrics

The models are evaluated using:

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix
